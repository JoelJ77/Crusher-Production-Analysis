# Crusher-Production-Analysis
This is a crusher production analysis of aggregates;3/4",1/2", stone base and stone dust.
The objective was to organize raw operational data, calculate summary metrics, identify patterns, and create visualizations that can support operational decision-making.

Tools used include:
Microsoft Excel
Excel formulas
Data cleaning
Data aggregation
Pivot Tables
Pivot Tables
Charts and visualization
Pareto analysis

Key Tasks:
Cleaned and organized the dataset
Calculated totals and derived metrics
Used Excel formulas to automate calculations
Summarized data by category
Created charts and visualizations
Performed Pareto analysis to identify major contributors
